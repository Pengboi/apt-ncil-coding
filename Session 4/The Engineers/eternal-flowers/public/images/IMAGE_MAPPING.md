## 🎯 Quick Setup Instructions

1. Save your flower photos to this folder: `/public/images/`
2. Use the filenames listed above
3. Run `npm run dev` to see your images live!
4. The website will automatically display your real photos

---

## 💡 Pro Tips

- Use **JPG** for photos (smaller file size)
- Use **WebP** for best performance (optional)
- Recommended size: **1200x1200px** for product images
- Keep file sizes under **500KB** for fast loading
- Use descriptive names so you can find them easily!
