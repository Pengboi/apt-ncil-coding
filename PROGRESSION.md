## 💎 Experience Points (XP) System

### How to Earn XP

| Action | XP Awarded | Description |
|--------|------------|-------------|
| **Quest Completion** | 50 XP | Finish a weekly session quest |
| **Boss Victory** | 100 XP | Defeat a major boss (Sessions 6, 12, 18, 24, 30) |
| **Mini-Boss Victory** | 25 XP | Defeat a mini-boss within a session |
| **Bonus Challenge** | 25 XP | Complete optional advanced challenges |
| **Creative Solution** | 30 XP | Unique, elegant, or artistic approach |
| **Peer Assistance** | 15 XP | Help another knight with their quest |
| **Bug Hunter** | 10 XP | Find and fix a bug (yours or another's) |
| **Perfect Execution** | 20 XP | Code works flawlessly first try |
| **Chronicle Commit** | 5 XP | Each Git commit with clear message |
| **Council Review** | 15 XP | Create a Pull Request for feedback |
| **Showcase Heroics** | 25 XP | Present your solution to the class |
| **Weekend Quest** | 40 XP | Complete take-home challenges |

### XP Multipliers

| Condition | Multiplier | Example |
|-----------|------------|---------|
| **Speed Run** (Finish early) | 1.5x | 50 XP → 75 XP |
| **Solo Challenge** (No hints) | 1.3x | 50 XP → 65 XP |
| **Teaching Moment** (Explain to peer) | 1.2x | 15 XP → 18 XP |
| **Double Trouble** (Two boss attempts) | 2x | 100 XP → 200 XP |

### XP Calculation Formula

```
Weekly XP = Base XP × Multipliers + Bonus XP

Example:
Quest Completion (50) × Speed Run (1.5) + Bug Hunter (10)
= 50 × 1.5 + 10
= 75 + 10
= 85 XP
```

## 🗡️ Boss Battle System

### Major Boss Battles (Every 6 Sessions)

#### Battle Format
1. **The Challenge** - Boss presents a complex problem
2. **Preparation Phase** - Use all skills learned in the phase
3. **Combat Phase** - Code the solution under time pressure
4. **Victory/Retry** - Boss defeated or learn and retry

### Boss Victory Conditions

#### 🐍 Basilisk of Infinite Loops (Session 6)
**Requirements to Win:**
- [ ] Create a Snake game that runs without infinite loops
- [ ] Implement proper game over conditions
- [ ] Add at least 2 custom features (speed, color, shape)
- [ ] Code uses at least one loop correctly
- [ ] Game ends properly (no hanging)

**Elite Victory (Bonus):**
- [ ] Add a scoring system
- [ ] Implement difficulty levels
- [ ] Create a "restart" feature

#### 👤 Shapeshifter of Null (Session 12)
**Requirements to Win:**
- [ ] Handle all null/undefined cases safely
- [ ] Validate all user inputs
- [ ] Use proper error handling (Try/Except)
- [ ] Data structures implemented correctly
- [ ] No crashes on edge cases

**Elite Victory (Bonus):**
- [ ] Custom error messages
- [ ] Input validation for all fields
- [ ] Graceful degradation

#### 🗿 Golem of Spaghetti Code (Session 18)
**Requirements to Win:**
- [ ] Code is modular (uses functions)
- [ ] No code duplication (DRY principle)
- [ ] Functions are under 20 lines each
- [ ] Clear naming conventions
- [ ] Proper separation of concerns

**Elite Victory (Bonus):**
- [ ] All functions documented
- [ ] Reusable components
- [ ] Clean architecture

#### 🦁 Chimera of Bad UX (Session 24)
**Requirements to Win:**
- [ ] Interface is intuitive
- [ ] Visual hierarchy is clear
- [ ] Responsive design works
- [ ] User can complete tasks without confusion
- [ ] Accessibility considered

**Elite Victory (Bonus):**
- [ ] Beautiful animations
- [ ] Delightful micro-interactions
- [ ] Mobile-optimized

#### 🤖 Titan of Artificial Chaos (Session 30)
**Requirements to Win:**
- [ ] AI integration works
- [ ] API calls are handled safely
- [ ] User input is sanitized
- [ ] Response is parsed correctly
- [ ] Full application is deployed

**Elite Victory (Bonus):**
- [ ] Multiple AI features
- [ ] Error handling for AI failures
- [ ] Creative use of AI capabilities

### Mini-Boss Battles (Within Sessions)

Each session contains optional mini-boss challenges:
- **Difficulty:** Moderate
- **Reward:** 25 XP + Mini-Boss Badge
- **Time Limit:** 15-20 minutes
- **Can be retried** until defeated
