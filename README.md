## 📖 Project Overview

This initiative has been designed to bridge the digital divide in the Barking & Dagenham borough. Securing funding from the **NCIL (Neighbourhood Community Infrastructure Levy)**, This comprehensive 30-week program has been created to provide underserved local youth with high-quality, industry-standard digital skills.

This repository hosts the custom curriculum, code samples, and architectural standards developed to take students from writing their first line of Python to building deployable web applications and AI apps.

## 🎯 Our Mission

To provide high-quality, industry-standard digital skills training to young people in Barking & Dagenham. We don't just teach theory; we build real things.

### 🧭 Group A: The Explorers (Ages 9–12)
*   **Strategy:** High-visual-impact learning. Focused on logic and immediate feedback loops to build engagement.
*   **Tech Stack:** Python (Turtle), Scratch, Basic Logic.

### 🛠️ Group B: The Engineers (Ages 13–18)
*   **Strategy:** Career-readiness. Treating this cohort like junior developers, introducing them to the exact tools and workflows used daily by industry leading tech companies.
*   **Tech Stack:** Python 3.10+, Visual Studio Code, Git/GitHub, LLMs / Agentic Agents.

## 📂 How to Use This Repository

We use **GitHub** just like professional software teams. Follow these steps to get the code onto your machine:

### 1. Fork this Repo
Click the **Fork** button in the top right corner of this page. This creates your own copy of the code that you can edit without affecting the main class repository.

### 2. Clone Your Fork
Open your terminal (Command Prompt or Git Bash) and run:
```bash
# Replace 'YOUR-USERNAME' with your actual GitHub username
git clone https://github.com/YOUR-USERNAME/APT-Coding-Camp.git
cd APT-Coding-Camp
```

### 3. Start Coding!
Navigate to the current session folder. For example, for our first class:
```bash
cd "Session 1"
code .
```

## 📅 Curriculum Roadmap

Our 30-week journey is broken into **Five Phases**. Each phase builds on the last — from your first line of Python to shipping AI-powered apps.

### Phase I — The Logic of Code (Sessions 1–6)
*Taming the serpent. Building instincts for logic, flow, and control.*

#### Session 1: The Logic of Gaming 🐍
*   **Project:** The Classic Snake Game
*   **Concepts:** Variables, Loops, Conditionals, and Coordinate Systems.
*   **Challenge:** Can you change the snake's speed, color, or make the game impossible to lose?

#### Session 2: Drawing with Code 🐢
*   **Project:** Turtle Graphics Art Gallery
*   **Concepts:** The `turtle` module, functions, pen control, and angles.
*   **Challenge:** Recreate a famous logo (Nike, Olympic rings, or your own brand) using only code.

#### Session 3: Choose Your Own Adventure 🧭
*   **Project:** Interactive Text Adventure Game
*   **Concepts:** Nested conditionals, boolean logic, and user input handling.
*   **Challenge:** Add three endings — heroic, tragic, and absurd — based on the player's choices.

#### Session 4: The Grid of Patterns 🎨
*   **Project:** Generative Spiral & Mandala Art
*   **Concepts:** Nested loops, modular arithmetic, and RGB color manipulation.
*   **Challenge:** Make your mandala change colors dynamically based on user input.

#### Session 5: Loops Within Loops 🧩
*   **Project:** Tic-Tac-Toe (text-based)
*   **Concepts:** 2D lists, game loops, win-state detection, and input validation.
*   **Challenge:** Add a simple AI opponent that blocks your winning moves.

#### Session 6: Phase I Boss — The Maze Runner 🗺️
*   **Project:** Random Maze Generator & Solver
*   **Concepts:** Combine everything from Phase I: loops, conditionals, 2D grids, and logic.
*   **Challenge:** Generate a new maze every time the game runs, then autopath the solution.

---

### Phase II — The Data Layer (Sessions 7–12)
*From single values to structures. Storing, organizing, and retrieving information.*

#### Session 7: Lists, Dictionaries & Tuples 📦
*   **Project:** Personal Contact Book
*   **Concepts:** Mutable vs. immutable data, key-value stores, and CRUD operations.
*   **Challenge:** Add a search function that finds contacts by partial name match.

#### Session 8: Files & Persistence 💾
*   **Project:** Save & Load Your Snake Game
*   **Concepts:** File I/O (`open`, `read`, `write`, `with`), JSON, and serialization.
*   **Challenge:** Add a leaderboard that persists across restarts.

#### Session 9: Error Handling & Validation 🛡️
*   **Project:** Robust Signup Form
*   **Concepts:** `try/except`, custom error messages, input sanitization, and edge-case testing.
*   **Challenge:** Make the form impossible to crash — try to break your own code first.

#### Session 10: Data Structures Deep Dive 🌲
*   **Project:** Task Manager with Priorities
*   **Concepts:** Stacks, queues, sets, and dictionaries in real-world scenarios.
*   **Challenge:** Implement a priority queue that reorders tasks automatically.

#### Session 11: Data Pagination & Filtering 🔍
*   **Project:** Movie Database Browser
*   **Concepts:** List comprehensions, filter/map/reduce patterns, and pagination.
*   **Challenge:** Add sort, filter, and search across 1,000+ mock records in under a second.

#### Session 12: Phase II Boss — The Inventory System 🎒
*   **Project:** RPG Inventory & Shop System
*   **Concepts:** Combine all Phase II skills into a single data-driven app.
*   **Challenge:** Implement a shop economy where prices fluctuate based on stock levels.

---

### Phase III — The Art of Functions (Sessions 13–18)
*Reusable code. Abstraction. Thinking like an engineer, not just a coder.*

#### Session 13: Functions & Abstraction ⚙️
*   **Project:** Refactor Snake into Modular Code
*   **Concepts:** Function design, parameters, return values, and single-responsibility principle.
*   **Challenge:** Break your existing Snake game into 6+ functions with no globals.

#### Session 14: Scope, Globals & Modules 📚
*   **Project:** Build Your Own Python Module
*   **Concepts:** Local/global scope, `import`, namespaces, and code organization.
*   **Challenge:** Create a `game_utils.py` module you can reuse across all your future projects.

#### Session 15: Object-Oriented Programming I 🧱
*   **Project:** Character Class Builder
*   **Concepts:** Classes, objects, attributes, and methods.
*   **Challenge:** Design three RPG classes (Knight, Mage, Archer) with unique stats and abilities.

#### Session 16: Object-Oriented Programming II 🏰
*   **Project:** Turn-Based Battle System
*   **Concepts:** Inheritance, `super()`, polymorphism, and composition.
*   **Challenge:** Implement a final boss that inherits from three enemy classes at once.

#### Session 17: Debugging & Testing 🐛
*   **Project:** Bug Hunt Tournament
*   **Concepts:** Stack traces, `pdb`, unit tests with `pytest`, and defensive programming.
*   **Challenge:** Find and fix 10 hidden bugs in our provided broken-game codebase — fastest wins.

#### Session 18: Phase III Boss — The Game Engine 🎮
*   **Project:** Mini Game Engine (Framework)
*   **Concepts:** Combine OOP, modules, and testing into a reusable codebase others can build on.
*   **Challenge:** Engineer it well enough that another student can build a new game using your engine in under an hour.

---

### Phase IV — The Domain of Interfaces (Sessions 19–24)
*Frontend. Shipping real, interactive web apps with React.*

#### Session 19: HTML, CSS & the DOM 🌐
*   **Project:** Personal Portfolio One-Pager
*   **Concepts:** Semantic HTML, CSS grid/flexbox, responsive layout, and accessibility basics.
*   **Challenge:** Make it look stunning on phone, tablet, and desktop — no broken layouts allowed.

#### Session 20: JavaScript Fundamentals ⚡
*   **Project:** Interactive To-Do List
*   **Concepts:** DOM manipulation, event listeners, localStorage, and ES6 syntax.
*   **Challenge:** Add drag-and-drop reordering and persistent saved state across reloads.

#### Session 21: Intro to React ⚛️
*   **Project:** React Component Library
*   **Concepts:** JSX, components, props, and component composition.
*   **Challenge:** Build 5 reusable UI components (Button, Card, Modal, Nav, Footer) and document them.

#### Session 22: React State & Events 🔄
*   **Project:** Live Reaction Poll App
*   **Concepts:** `useState`, `useEffect`, event handling, and controlled inputs.
*   **Challenge:** Make votes update in real-time across two browser windows using `localStorage` sync.

#### Session 23: APIs & Fetch 🌍
*   **Project:** Weather Dashboard
*   **Concepts:** REST APIs, `fetch`, async/await, JSON parsing, and loading/error states.
*   **Challenge:** Add a 5-day forecast view with a city search that handles 404s gracefully.

#### Session 24: Phase IV Boss — The Full Web App 🚀
*   **Project:** Capstone Frontend (Student's Choice)
*   **Concepts:** Combine HTML, CSS, JS, React, and APIs into one polished product.
*   **Challenge:** Deploy it live (Netlify/Vercel) and ship a real URL you can share with friends, family, and future employers.

---

### Phase V — The Mastery of Intelligence (Sessions 25–30)
*AI, LLMs, and agents. Coding alongside machines, not against them.*

#### Session 25: Intro to AI & LLMs 🤖
*   **Project:** Conversational AI Assistant
*   **Concepts:** Prompt engineering, the OpenAI/Anthropic API, token usage, and system prompts.
*   **Challenge:** Build an assistant with a distinct personality (pirate, robot, detective — your pick).

#### Session 26: Prompt Engineering & RAG 🔍
*   **Project:** "Chat With Your Notes" App
*   **Concepts:** Retrieval-Augmented Generation, document chunking, embeddings, and context windows.
*   **Challenge:** Upload your class notes and have the AI answer questions only using your uploaded material.

#### Session 27: Multi-Step Agents 🧠
*   **Project:** Research Agent
*   **Concepts:** Tool use, function calling, agent loops, and multi-step reasoning.
*   **Challenge:** Build an agent that plans, searches, summarizes, and cites sources autonomously.

#### Session 28: Building with AI Frameworks 🛠️
*   **Project:** AI-Powered Mini App
*   **Concepts:** Frameworks (LangChain/OpenAI Agents SDK), structured outputs, and chaining tools.
*   **Challenge:** Ship an app that uses at least two tools (search + calculator + API) in a single run.

#### Session 29: Ethics, Bias & Responsible AI ⚖️
*   **Project:** AI Red-Team Exercise
*   **Concepts:** Bias detection, prompt injection, safety evals, and the social impact of AI.
*   **Challenge:** Break your own AI app in 5 different ways — then patch each vulnerability.

#### Session 30: Final Boss — Ship Your Product 🏆
*   **Project:** Final Capstone (team or solo)
*   **Concepts:** Everything you have learned across 30 sessions — design, build, deploy, and present.
*   **Challenge:** Present a complete, deployed AI-powered application to the cohort, family, and partners. This is your graduation.
