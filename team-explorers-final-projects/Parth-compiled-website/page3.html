More information

For better responses, you need to first enhance your prompt.
You can ask AI to give you a complex prompt from a simple prompt.

Or you can use the CREATE technique:

Character (or Context): Defining the persona or role the AI should adopt (e.g., "Act as an expert python programmer").

Request: Clearly and specifically defining the task you want the AI to perform (e.g., "Write a script to...").

Examples: Providing sample outputs or input-output pairs to guide the style, tone, or format.

Adjustments (or Additions/Constraints): Refining the prompt with additional instructions, constraints, or stylistic preferences (e.g., "Avoid jargon," "Keep it under 100 words").

Type of Output (or Type): Specifying the format of the response (e.g., a table, a list, code block, Markdown).

Extras (or Evaluation/Context): Including any additional background information, reference text, or instructions to ensure the model produces the best possible result.
